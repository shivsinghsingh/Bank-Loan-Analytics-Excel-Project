# Bank Loan Analytics – Excel Project

## 📊 Project Overview

This project analyzes a bank loan dataset using Microsoft Excel.

The objective is to understand loan applications, approval status, loan amounts, customer demographics, credit scores, income, interest rates, and other loan-related insights.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Charts
- Excel Dashboard

## 📁 Dataset

The dataset contains 500 loan records with the following columns:

- Loan ID
- Customer Name
- Gender
- Age
- City
- Employment Type
- Monthly Income
- Credit Score
- Loan Type
- Loan Purpose
- Loan Amount
- Interest Rate
- Loan Tenure (Months)
- EMI
- Application Date
- Approval Date
- Loan Status

## 📌 Key KPIs

The dashboard includes:

- Total Loan Applications
- Total Loan Amount
- Approved Loans
- Rejected Loans
- Average Loan Amount
- Average Credit Score
- Average Monthly Income
- Average Interest Rate
- Total EMI

## 📈 Dashboard Analysis

The dashboard provides analysis of:

- Loan Status-wise Applications
- Loan Type-wise Applications
- Loan Purpose-wise Applications
- City-wise Loan Applications
- Employment Type-wise Applications
- Gender-wise Loan Applications
- Age Group-wise Loan Applications
- Total Loan Amount by Loan Type
- Average Credit Score by Loan Type

## 🎯 Project Objectives

- Analyze overall loan application performance
- Understand approved and rejected loans
- Compare different loan types and purposes
- Analyze customer demographics
- Study credit score and income patterns
- Understand loan amount and interest rate trends
- Create an interactive and professional Excel dashboard

## 📷 Dashboard

The project includes an Excel dashboard with KPI cards, Pivot Tables, and charts for easy data visualization and analysis.
